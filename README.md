🚀 My First Streamlit App

A simple interactive web app built using Python and Streamlit.

✨ Features

- 👤 Enter Name & Age
- 📊 Display Sample Data
- 📈 Line Chart
- 🔘 Interactive Button
- ☑️ Show Code

🛠️ Technologies

- Python
- Streamlit
- Pandas
- NumPy

▶️ Run

pip install streamlit pandas numpy
streamlit run app.py
